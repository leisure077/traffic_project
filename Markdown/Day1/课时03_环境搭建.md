# 课时 03：环境搭建与项目运行

## 一、学习目标

- 准备好 Python 运行环境和三个第三方库；
- 学会在命令行运行 Python 脚本、安装依赖；
- 成功把项目跑起来（看到 7 个 CSV、6 张图）。

## 二、需要安装什么

| 名称 | 作用 | 本项目验证版本 |
| --- | --- | --- |
| Python | 运行环境，建议 3.9 以上 | 3.11 |
| pandas | 表格数据处理（读 CSV、过滤、分组、连接、时间） | 2.2.3 |
| numpy | 多维数组与数值计算（距离、广播、聚类） | 1.26.4 |
| matplotlib | 画图（6 张图） | 3.10.9 |

> 不需要安装 sklearn、geopandas——本项目刻意手写算法。

## 三、安装步骤（Windows）

### 1. 确认 Python

打开 PowerShell（或 CMD），输入：

```powershell
python --version
```

能看到 `Python 3.x.x` 即可。机房已装好的同学可跳过。

### 2. 安装依赖（推荐用项目自带的 requirements.txt）

进入项目目录后执行：

```powershell
cd traffic_project
python -m pip install -r requirements.txt
```

`requirements.txt` 内容：

```text
pandas>=2.0
numpy>=1.24
matplotlib>=3.7
```

### 3. 验证库是否装好

```powershell
python -c "import pandas, numpy, matplotlib; print(pandas.__version__, numpy.__version__, matplotlib.__version__)"
```

能打印三个版本号即成功。

## 五、三种运行方式

### 方式 A：一键跑完整流程（推荐）

```powershell
python main.py
```

约 24 秒跑完，末尾会打印"结果核对"，7 个 CSV 和 6 张图应全部显示 `[OK]`。

### 方式 B：只跑某个模块（边学边调）

```powershell
python data_clean.py     # 只做清洗
python tr_stage2.py      # 只做聚类（前提：上游结果已存在）
```

每个模块文件末尾都有：

```python
if __name__ == "__main__":
    clean_data()
```

含义：直接运行这个文件时执行该函数；被 `import` 时不自动执行。

### 方式 C：验证配置 / 检查数据文件是否找得到

```powershell
python config.py
```

会打印数据目录、全部阈值，并检查 6 个数据文件是否 `[OK]`。

## 六、数据放哪里（路径问题）

`config.py` 会按下面顺序自动找"相关数据"文件夹：

1. 环境变量 `TRAFFIC_DATA_DIR`；
2. 项目下的 `traffic_project/data/` 目录（把 6 个 CSV 复制进去即可）；
3. 自动在各盘符两层目录里搜索名为"相关数据"、且含"原始数据.csv"的文件夹。

如果运行报 `FileNotFoundError: 文件不存在`，优先按上面三种方式之一处理。

## 七、常见报错与处理

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'pandas'` | 库没装 | `python -m pip install pandas` |
| `FileNotFoundError: 文件不存在: …原始数据.csv` | 数据没找到 | 见第六节，放进 `data/` 或设环境变量 |
| 图里中文显示成方框 | 缺 SimHei 字体 | 代码已自动回退微软雅黑；仍不行可安装 SimHei |
| `UnicodeDecodeError` 读 CSV 报错 | 编码不对 | 目的/方式静态数据是 GBK，用 `encoding='gbk'`（Day3 讲） |

# 课时 01：课程导学与项目全景

## 一、这门课在解决什么问题？

城市里每天有几千万人在移动。传统调查靠**问卷**：发几万张表、回收、录入，又慢又贵，而且人未必如实填写。

现在每个人都带手机。手机只要开机，就会不断连接附近的**通信基站**，在运营商那里留下一条条"**信令**"记录：什么时间、哪个手机（匿名编号）、连了哪个基站、基站大概在什么位置。

> 这就是**手机信令数据（Mobile Signaling Data）**——一种天然的、海量的、实时的"人的位置轨迹"。

用它可以回答一系列交通问题：

- 一个人一天里**什么时候待着不动、什么时候在赶路**？（出行 / 驻留识别）
- 他在一个地方停留很久，**是回家、逛商场还是旅游**？（出行目的）
- 他赶路时**坐地铁、公交还是开车**？（出行方式）
- **哪个商圈、几点钟人最多**？（实时热力，可用于交通疏导、商圈选址）

本项目就用真实的手机信令数据，把上面 4 类问题完整做一遍，并可视化。

## 二、最终成果长什么样

8 天后，你会得到一套 `traffic_project/` 代码，运行 `python main.py`，约 24 秒产出：

- **7 个结果表（CSV）**：清洗结果、出行点、聚类、最终标签、出行目的、出行方式、商圈热力；
- **6 张图（PNG）**：出行/驻留占比饼图、24 小时变化折线、目的与方式柱状图、商圈热力矩阵、Top5 用户 3D 轨迹图。

这些就是你简历上"**交通时空大数据分析与可视化系统**"的实证。

## 三、整条技术路线（先混个脸熟，后面每天细化）

```
原始信令 → 清洗 → 速度粗筛 → K-Means聚类 → 规则精判 → 目的/方式/热力 → 可视化
data_clean  tr_stage1   tr_stage2     tr_stage3    purpose/mode/heatmap  visualize
```

打个比方，整条流水线像"**从河里淘金**"：

1. **清洗**：把浑水、石头滤掉（脏数据、缺字段、不是今天的、太稀疏的用户）；
2. **粗筛**：先用"移动速度快不快"把明显在动的沙子捞出来；
3. **聚类**：把动的点按"聚成几堆"分类（K-Means，像把人群分到不同的桌子）；
4. **精判**：再看每一堆点是不是真的在移动（离中心远不远、持续时间长不长）；
5. **目的/方式/热力**：在"停留"和"移动"的基础上，结合地图静态数据（小区、商场、景点、地铁站）做推断；
6. **可视化**：把结果画成图，让人一眼看懂。

## 四、为什么这门课"只手写、不调库"

很多教程做聚类直接 `from sklearn.cluster import KMeans`，一行搞定——但面试时面试官问"K-Means 每一步在干什么？为什么要多次初始化？K 怎么选？"就答不上来了。

本项目**刻意不使用** sklearn / geopandas：

- **K-Means 自己写**（课时 36）：随机选中心 → 分配 → 更新中心 → 迭代；
- **选 K 自己算**（课时 37）：轮廓系数 + 邓恩指数；
- **地球表面距离自己写**（课时 13）：Haversine 公式，因为经纬度不能直接用直尺量；
- **滑窗自己实现**（课时 53）：理解"最近 10 分钟人流量"。

底层只用 `numpy`（数值计算）、`pandas`（表格处理）、`matplotlib`（画图）三个库。

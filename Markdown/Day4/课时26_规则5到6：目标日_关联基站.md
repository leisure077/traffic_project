## 规则 5：只保留目标日 20181003

抽样里混着 10 月 1~3 日的数据，而我们只分析一天：

```python
before = len(df)
df = df[df["time"].str.startswith(TARGET_DATE)]   # TARGET_DATE="20181003"
print(before, "->", len(df))
```

此时 time 已是 `YYYYMMDDHHMMSS` 字符串，前 8 位即日期，用 startswith 最直接。

实跑（全量到这一步）：532811 → 518427（删跨天 14384 行）。

> 若上一课忘了 +8，很多 10 月 3 日凌晨的点会被错判成 10 月 2 日而误删——这就是时间转换必须正确的原因。

## 规则 6：拼 laci，左连接基站表补经纬度

信令只有基站编号，经纬度要查"基站经纬度数据.csv"。

### 第一步：读基站表（无表头，真实列序 lon,lat,laci）

```python
station = pd.read_csv(STATION_DATA_FILE, header=None,
                      names=["lon", "lat", "laci"], dtype=str)
station["lon"] = pd.to_numeric(station["lon"], errors="coerce")
station["lat"] = pd.to_numeric(station["lat"], errors="coerce")
station = station.dropna(subset=["lon", "lat", "laci"]).drop_duplicates("laci")
```

注意：

- 真实文件列序是 **lon, lat, laci**（讲义有时假设相反），按真实顺序命名；
- lon/lat 转数值；
- **去重 laci**，避免 merge 一对多导致行数翻倍。

### 第二步：拼连接键 laci

```python
df["laci"] = df["lac_id"].astype(str) + "-" + df["cell_id"].astype(str)
# 16481 + - + 536531 = 16481-536531
```

### 第三步：左连接 + 删除匹配失败行

```python
df = df.merge(station[["laci", "lon", "lat"]], on="laci", how="left")
df = df.dropna(subset=["lon", "lat"])
```

- 左连接保留所有信令点，匹配到的补 lon/lat，匹配不到的是 NaN；
- 再 dropna 删除没有坐标的点（没有坐标无法做任何空间分析）。

实跑（抽样后）：19985 → 19983（仅 2 行匹配失败），匹配率接近 100%。

## 为什么先抽样再关联（工程顺序）

本课在代码里的实际顺序是：规则 1~5 → **按整用户抽样** → 规则 6 关联。先把行数从 51.8 万降到约 2 万，再做 merge，计算量更小（课时 28 专门讲抽样）。无论先抽样还是先关联，最终结果都只包含抽样用户，不影响正确性。

# 课时 24：规则 1~3（字段抽取、去脏 imsi、去空基站编号）

## 规则 1：字段抽取——只读需要的 4 列

原始 10 列，但只用到时间戳、imsi、lac_id、cell_id。用 `usecols` 只取前 4 列，并手动命名：

```python
RAW_COLUMNS = ["time", "imsi", "lac_id", "cell_id"]
df = pd.read_csv(RAW_DATA_FILE, header=None, usecols=[0, 1, 2, 3],
                 names=RAW_COLUMNS, dtype=str)
```

要点回顾：

- `header=None`：第一行就是数据；
- `usecols=[0,1,2,3]`：不读多余列，省内存；
- `dtype=str`：编号当字符串，避免前导零丢失、长数字变科学计数法。

实跑：原始 532828 行。

## 规则 2：去脏 imsi

正常 imsi 是纯数字编号，少量记录混入了 `#`、`*`、空格等：

```python
before = len(df)
df = df[~df["imsi"].str.contains(r"[#* ^\s]", na=False, regex=True)]
print(before, "->", len(df))
```

正则字符集 `[#* ^\s]` 解释：

- `#`、`*`、空格：字面字符；
- `\s`：任意空白（制表符等）；
- 外层 `~`：取反，保留"不含这些字符"的行；
- `na=False`：万一 imsi 是空，按 False（不当脏、交给规则3处理）。

实跑：532828 → 532820（删 8 行）。

## 规则 3：去空 lac_id / cell_id

没有基站编号就无法定位，直接删。要同时处理 `NaN` 和空字符串两种"空"：

```python
df = df.dropna(subset=["lac_id", "cell_id"])
df = df[(df["lac_id"].str.strip() != "") &
        (df["cell_id"].str.strip() != "")]
```

- `dropna`：删除真正的缺失 NaN；
- `str.strip() != ""`：删除全是空格的串；
- 用 `&` 连接两个条件，各自加括号。

实跑：532820 → 532811（删 9 行）。

## 为什么规则 2、3 放在最前面

脏编号、空编号若留到后面：

- 拼 laci 会得到 `nan-nan` 这种垃圾键；
- 时间转换、分组统计也会混入异常记录；
- 越早删除，后面越省事。

清洗的通用顺序原则：**先做不依赖其他字段、能立刻确定的过滤**（格式问题），再做需要转换/关联的处理。

## 课堂动手

```python
import pandas as pd
df = pd.read_csv(r"...\原始数据.csv", header=None,
                 usecols=[0,1,2,3],
                 names=["time","imsi","lac_id","cell_id"], dtype=str)
print(df.shape)

n0 = len(df)
df = df[~df["imsi"].str.contains(r"[#* ^\s]", na=False, regex=True)]
print("去脏:", n0, "->", len(df))

n1 = len(df)
df = df.dropna(subset=["lac_id","cell_id"])
df = df[(df["lac_id"].str.strip()!="") & (df["cell_id"].str.strip()!="")]
print("去空:", n1, "->", len(df))
```

# 课时 23：数据清洗总览（9 条规则地图）

## 一、为什么清洗占比最大

行业常说"数据工作 70% 时间在清洗"。原始信令有跨天、脏编号、缺字段、毫秒 UTC 时间、无经纬度、重复、稀疏用户等问题，不清洗直接算速度/聚类，结果全是错的。

`data_clean.py` 用 **9 条规则**把 53 万行原始数据变成干净的六列表：

```
imsi, time, lac_id, cell_id, lon, lat
```

## 二、9 条规则一览

| 规则 | 做什么 | 关键技术 |
| --- | --- | --- |
| 1 | 字段抽取：10 列只取前 4 列 | `read_csv(header=None, usecols, names, dtype=str)` |
| 2 | 去脏 imsi（含 `# * 空格`） | 正则 `str.contains` + 取反 |
| 3 | 去空 lac_id / cell_id | dropna + 非空串 |
| 4 | 毫秒 UTC 时间戳转北京时间 | `to_datetime(unit='ms')` + `Timedelta(hours=8)` |
| 5 | 只留目标日 20181003 | `str.startswith` |
| （抽样） | 按整用户抽样约 2 万行 | groupby + 整用户纳入 |
| 6 | 拼 laci 关联基站补 lon/lat | merge 左连接 + dropna |
| 7 | 按 imsi+time 排序 | sort_values |
| 8 | 同一用户同一分钟去重 | 前 12 位时间键 + drop_duplicates |
| 9 | 删除点数 <20 的稀疏用户 | groupby.size + isin |

## 四、主函数骨架

```python
def clean_data():
    df = read_raw()                       # 规则1
    df = rule2_dirty_imsi(df)             # 规则2
    df = rule3_empty_lac_cell(df)         # 规则3
    df = rule4_timestamp(df)              # 规则4
    df = rule5_target_date(df)            # 规则5
    df = sample_by_user(df)               # 教学抽样（非规则）
    df = rule6_join_station(df)           # 规则6
    df = rule7_sort(df)                   # 规则7
    df = rule8_dedup_minute(df)           # 规则8
    df = rule9_filter_sparse(df)          # 规则9
    save_csv(df[["imsi","time","lac_id","cell_id","lon","lat"]], CLEANED_DATA_FILE)
    return df
```

实际代码用 `with Timer("规则x ..."):` 包裹每一步并打印 before→after。

## 五、两个贯穿全项目的意识

1. **每步留痕**：打印每步删了多少行，出问题立刻能定位；
2. **以真实数据为准**：无表头、毫秒 UTC、GBK、4 列实时流等，都和讲义描述不完全一致，代码按真实文件适配。

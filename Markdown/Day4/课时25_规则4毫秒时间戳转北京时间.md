# 课时 25：规则 4——毫秒 UTC 时间戳转北京时间（重点难点）

## 一、先看清原始时间长什么样

```python
df["time"].head()
# 0    1538498482636
# 1    1538498501200
# ...
```

13 位整数。判断方法：

- 10 位是秒级，13 位是毫秒级；
- `1538... × 1000` 量级，对应 2018 年。

## 二、三个必须做对的点

1. 字符串先转数值；
2. 按**毫秒** `unit='ms'` 解析；
3. 原始是 **UTC**，必须 **+8 小时**才是北京时间。

## 三、完整代码

```python
num = pd.to_numeric(df["time"], errors="coerce")
if num.notna().all() and (num.abs() >= 10**12).all():
    dt = pd.to_datetime(num.astype("int64"), unit="ms", utc=True) \
         + pd.Timedelta(hours=RAW_TIMEZONE_OFFSET_HOURS)   # =8
    df["time"] = dt.dt.tz_convert(None).dt.strftime("%Y%m%d%H%M%S")
else:
    df["time"] = pd.to_datetime(df["time"], errors="coerce").dt.strftime("%Y%m%d%H%M%S")
```

逐行拆解：

| 代码 | 作用 |
| --- | --- |
| `pd.to_numeric(..., errors='coerce')` | 字符串转数字，坏值变 NaN |
| `num.abs() >= 10**12` | 判断是否 13 位毫秒戳（≥1×10¹²） |
| `to_datetime(..., unit='ms', utc=True)` | 毫秒整数 → UTC 时间（带时区） |
| `+ Timedelta(hours=8)` | UTC → 北京时间 |
| `dt.tz_convert(None)` | 去掉 tz 标记，得到无时区时间，便于后续格式化 |
| `strftime('%Y%m%d%H%M%S')` | 统一成 `YYYYMMDDHHMMSS` 字符串 |

## 四、亲手验证一条

```python
import pandas as pd
t = pd.to_datetime(1538498482636, unit="ms", utc=True) + pd.Timedelta(hours=8)
print(t.tz_convert(None).strftime("%Y%m%d%H%M%S"))
# 20181003004122
```

即 2018-10-03 00:41:22（北京时间）。

## 五、两个真实"坑"（讲义代码的不足）

1. **讲义只做了毫秒转换、忘了 +8**：会把凌晨的点错算到前一天，目标日过滤大量误删；
2. **讲义假设列名已经存在**：真实文件无表头，必须先在规则 1 用 `names=` 命名。

## 六、为什么统一成字符串而不是保留 datetime

后续我们同时需要：

- 字符串前缀判日期：`time.startswith("20181003")`；
- 前 12 位做分钟去重：`time[:12]`；
- 需要计算时再用 `parse_time()`（即 `pd.to_datetime`）转回 datetime。

统一存成紧凑的 `YYYYMMDDHHMMSS` 字符串，排序、过滤、做键都方便，需要时间运算时再转。

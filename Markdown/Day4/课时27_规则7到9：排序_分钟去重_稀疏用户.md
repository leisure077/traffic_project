# 课时 27：规则 7~9（排序、分钟去重、过滤稀疏用户）

## 规则 7：按 imsi + time 排序

```python
df = df.sort_values(["imsi", "time"]).reset_index(drop=True)
```

为什么必须排序：阶段1要用 `groupby(imsi).shift(1)` 找"同一用户上一条记录"算速度和切段。不排序，"上一行"可能是别的时间甚至别的用户，结果全错。

## 规则 8：同一用户同一分钟去重

手机在一分钟内可能连上同一基站多次，产生重复记录。不去重会：

- 时间差为 0 → 速度除零（inf）；
- 把一次停留重复计数。

用时间前 12 位（精确到分钟）做去重键：

```python
df["_minute"] = df["time"].str[:12]          # 201810031230
df = df.drop_duplicates(subset=["imsi", "_minute"], keep="first")
df = df.drop(columns=["_minute"])
```

- `subset`：同一 imsi 且同一分钟视为重复；
- `keep="first"`：保留该分钟第一条；
- 用完删掉临时列。

实跑：19983 → 17400（删 2583 行），可见一分钟内重复相当多。

## 规则 9：过滤记录太少的用户

只有零星几条点的用户，轨迹无法可靠判断出行/驻留，直接剔除：

```python
counts = df.groupby("imsi").size()
valid_users = counts[counts >= MIN_POINTS_PER_USER].index   # >=20
df = df[df["imsi"].isin(valid_users)].reset_index(drop=True)
```

- `groupby(imsi).size()`：每用户点数；
- 取 ≥20 的用户集合；
- isin 过滤。

实跑：17400 → 17362 行、196 个用户（抽样用户本就活跃，仅极少数因去重跌破 20 点被删）。

## 完整 9 条规则的"为什么"复盘

| 规则 | 解决的真实问题 |
| --- | --- |
| 1 抽取 | 10 列只需 4 列；无表头要命名 |
| 2 去脏 | imsi 混入特殊字符 |
| 3 去空 | 缺基站编号无法定位 |
| 4 时间 | 毫秒 UTC 要转北京时间 |
| 5 日期 | 混着跨天数据 |
| 6 关联 | 信令只有基站编号，要补经纬度 |
| 7 排序 | 相邻点分析的前提 |
| 8 去重 | 一分钟多条导致重复/除零 |
| 9 稀疏 | 点数太少无法判断 |

## 一、问题：能不能仅凭信令知道一个人"在干嘛"？

不能 100% 确定，但可以**推断**。本项目把驻留目的分成四类：

- **居住**：在家（通常夜间、停留久）；
- **购物**：在商场/商圈；
- **旅游**：在景点；
- **其他**：无法归入上述。

推断依据有两类：

1. **时间特征**：停留多久、什么时间开始结束；
2. **空间特征**：停留中心附近是什么 POI（小区/商场/景点静态数据）。

分析单元不再是"单个点"，而是"**驻留段**"——连续一串停留点代表一次在某地的活动。

## 二、切驻留段：出行点把停留"打断"

在阶段3标签里，label=0 是停留、label=1 是出行。连续的 0 属于同一个驻留段，遇到 1（或换用户）就开新段。

这正是课时 32 的"变化标记+cumsum"通用模式：

```python
df = read_csv(STAGE3_LABEL_FILE, ...)
df["time_dt"] = parse_time(df["time"])
df = df.sort_values(["imsi","time"]).reset_index(drop=True)

user_change = (df["imsi"] != df["imsi"].shift(1)).astype(int)
break_by_travel = (df["label"] == 1).astype(int)
df["stay_seg"] = (user_change + break_by_travel).groupby(df["imsi"]).cumsum()

stay = df[df["label"] == 0]      # 只保留驻留点参与聚合
n_seg = stay.groupby(["imsi","stay_seg"]).ngroups
```

和阶段1切段的区别：

- 阶段1：位置一变就切段（坐标相同才算同段）；
- 这里：**只有出行点 label=1 才打断**，小范围内的驻留点即使坐标略有变化也算同一次驻留——因为阶段3已把"小范围活动"判定为驻留。

实跑：切出 **740 个驻留段**（含单点段，这里**不**过滤单点段）。

## 三、为什么不过滤单点驻留段

出行方式识别会过滤"单点出行段"（一个点没法算速度）。但驻留段即使只有一个点，也可能代表一次短暂活动，仍值得推断目的（配合时间和附近 POI）。所以 purpose 保留所有驻留段。

## 四、整体流程预告

```
stage3_label
  → 切驻留段（label=1 打断）
  → 段聚合：起止时间、点数、中心经纬度、时长、起止小时
  → POI最近邻匹配（段中心 → 最近的小区/商场/景点）
  → decide_purpose：时间规则(居住) + 空间证据(购物/旅游) + 时间兜底
  → purpose_result.csv
```

# 课时 44：出行目的（中）——驻留段特征聚合

## 一、一个驻留段需要哪些特征

要判断"在干嘛"，至少需要：

| 特征 | 含义 | 用途 |
| --- | --- | --- |
| start_time / end_time | 段首、段尾时间 | 计算时长、起止时刻 |
| points | 段内点数 | 衡量停留的"信号强度" |
| center_lon / center_lat | 段内点坐标均值 | 段的代表位置，用于匹配 POI |
| duration_hours | 停留小时数 | 居住判据（>4h） |
| start_hour / end_hour | 起止小时（0-23） | 夜间/购物/旅游时间窗 |

## 二、用 groupby + agg 一次聚合

```python
agg = stay.groupby(["imsi","stay_seg"]).agg(
    start_time=("time_dt", "min"),
    end_time=("time_dt", "max"),
    points=("time", "count"),
    center_lon=("lon", "mean"),
    center_lat=("lat", "mean"),
).reset_index()

agg["duration_hours"] = (agg["end_time"] - agg["start_time"]).dt.total_seconds() / 3600.0
agg["start_hour"] = agg["start_time"].dt.hour
agg["end_hour"] = agg["end_time"].dt.hour
```

命名聚合：`新列名=("被聚合列", "函数")`。时间差用 `.total_seconds()` 换成秒再除 3600 得小时。

## 三、夜间判定

```python
def is_night(hour):
    return (0 <= hour <= 6) or (20 <= hour <= 23)
```

居住判据需要"段首或段尾在夜间"（在家过夜的典型特征）。注意用的是**端点时刻**是否在夜间，配合停留时长。

## 四、段中心的含义

`center_lon/lat` 是段内所有驻留点的均值（重心）。小范围活动（逛商场、小区内移动）的点均值能代表"活动地点"，拿它去匹配最近 POI 比用任意单点更稳。

## 五、聚合后的表长什么样（示例结构）

```
imsi  stay_seg  start_time  end_time  points  center_lon  center_lat
u1    0         00:12:00    07:30:00  41      123.40      41.82
u1    2         10:05:00    11:40:00  9       123.43      41.80
...
duration_hours  start_hour  end_hour
7.3             0           7
1.58            10          11
```

第一行：深夜停留 7.3 小时 → 很可能是居住；第二行：上午停留 1.5 小时 → 购物或旅游（结合 POI）。

## 六、真实规模

- 740 个驻留段；
- POI 最近邻匹配成功 683/740（段中心 1km 内有 POI），匹配率很高，因为城区 POI 密集；

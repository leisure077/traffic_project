## 一、读入两张表

```python
cleaned = read_csv(CLEANED_DATA_FILE, dtype={"imsi":str,"lac_id":str,"cell_id":str})
cluster = read_csv(STAGE2_CLUSTER_FILE, dtype={"imsi":str})
```

- cleaned：17362 个点（全量，含大量停留点）；
- cluster：806 个带 cluster、is_single_cluster 的出行点。

## 二、左连接把簇贴回全量点

```python
df = cleaned.merge(
    cluster[["imsi","time","cluster","is_single_cluster"]],
    on=["imsi","time"], how="left")
df["cluster"] = df["cluster"].fillna(-1).astype(int)
df["is_single_cluster"] = df["is_single_cluster"].fillna(0).astype(int)
df["time_dt"] = parse_time(df["time"])
df = df.sort_values(["imsi","time"]).reset_index(drop=True)
df["label"] = 0     # 默认全部驻留
```

要点：

1. **双键 `[imsi,time]` 左连接**：不同用户同一时刻都有点，不能只用 time；
2. 未匹配点 cluster 为 NaN → 用 **-1** 表示"没有参与聚类"，fillna 后转 int；
3. 排序保证每个簇内部按时间有序，首/中/尾才有意义；
4. **label 先全部置 0**，只有确认是出行的簇才改成 1（保守策略：宁可少判出行，不把停留误判成赶路）。

## 三、遍历每个簇

```python
clustered = df[df["cluster"] >= 0]
for (imsi, cid), g in clustered.groupby(["imsi","cluster"], sort=False):
    idx = g.index
    ...
```

- `df[df["cluster"] >= 0]`：只处理真正有簇的 806 个点；
- 按 `(imsi, cluster)` 分组，每个 g 是"某用户的某一簇"；
- 记住 `g.index`，判定后用 `df.loc[idx, "label"] = 1` 回写。

## 四、单点簇：直接判出行

```python
if int(g["is_single_cluster"].iloc[0]) == 1 or len(g) == 1:
    df.loc[idx, "label"] = 1
    n_single_travel += 1
    continue
```

- `is_single_cluster==1`（阶段2已标）或当前簇只有 1 个点；
- 孤立点无法算"展布/跨度"，而它本身来自速度>8 的出行点，直接判出行；
- 实跑：152 个单点簇判出行。

## 五、为什么单点簇不会被误当驻留

驻留的定义需要"在一个小区域停留"。单点没有任何停留证据，且它是高速移动点，按出行处理更合理。这也避免单点簇在后面的均值/时间跨度计算中产生无意义结果。

## 六、一个 merge 细节：左连接后行数必须不变

```python
assert len(df) == len(cleaned)
```

（理解即可，项目靠 cluster 表预先按 laci/键去重保证。）若右表 `(imsi,time)` 有重复，左连接会一对多让行数膨胀，进而 label 重复。阶段2每个出行点只有一行，所以安全。

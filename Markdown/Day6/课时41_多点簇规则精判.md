# 课时 41：阶段3（下）——多点簇的三点距离 + 时间跨度精判

## 一、多点簇判据

对一个含多个点的簇（接上课，已排除单点簇）：

1. 簇中心 = 所有点经纬度均值；
2. 取首点 `iloc[0]`、中点 `iloc[len//2]`、尾点 `iloc[-1]`；
3. 分别算三点到中心的 Haversine 距离（米）；
4. 算首末时间跨度（小时）；
5. 当且仅当 **三距都 < 1000m 且 时间跨度 < 2h** → 驻留 0；否则出行 1。

## 二、代码实现

```python
n_multi_travel = 0
n_multi_stay = 0
for (imsi, cid), g in clustered.groupby(["imsi","cluster"], sort=False):
    idx = g.index
    if int(g["is_single_cluster"].iloc[0]) == 1 or len(g) == 1:
        df.loc[idx, "label"] = 1
        n_single_travel += 1
        continue

    # 簇中心
    center_lon = g["lon"].mean()
    center_lat = g["lat"].mean()
    first, mid, last = g.iloc[0], g.iloc[len(g)//2], g.iloc[-1]

    # 三点到中心距离（米，用Haversine真实距离）
    d_first = haversine(center_lon, center_lat, first["lon"], first["lat"], unit="m")
    d_mid   = haversine(center_lon, center_lat, mid["lon"],   mid["lat"],   unit="m")
    d_last  = haversine(center_lon, center_lat, last["lon"],  last["lat"],  unit="m")

    # 首末时间跨度（小时）
    time_span_h = (last["time_dt"] - first["time_dt"]).total_seconds() / 3600.0

    is_stay = (d_first < CLUSTER_DIST_THRESHOLD and
               d_mid   < CLUSTER_DIST_THRESHOLD and
               d_last  < CLUSTER_DIST_THRESHOLD and
               time_span_h < TIME_SPAN_THRESHOLD)
    if is_stay:
        n_multi_stay += 1                 # 保持 label=0
    else:
        df.loc[idx, "label"] = 1
        n_multi_travel += 1
```

注意：簇中心虽然在经纬度平面用均值求，但三点到中心距离用 **Haversine（米）**，这样才能和 1000m 阈值直接比较——又一次体现"聚类用平面近似、判阈值用真实距离"的分工。

## 四、判据背后的语义

| 情况 | 三点到中心 | 时间跨度 | 判定 | 现实含义 |
| --- | --- | --- | --- | --- |
| 小范围、短时间 | 都<1km | <2h | 驻留 0 | 在一处短暂活动（办事、就餐） |
| 拉开很长 | 某点≥1km | 任意 | 出行 1 | 空间上确实在移动 |
| 小范围但持续很久 | 都<1km | ≥2h | 出行 1 | 说明聚类把不同时段的"回访同片区"混到一起，不算一次驻留段 |
| 单点簇 | — | — | 出行 1 | 孤立高速点 |

最后一行值得讨论："小范围但 ≥2h 也判出行"是讲义给定口径，可在课堂作为"阈值工程没有唯一答案"的讨论点——你也可以尝试改成更贴近业务的规则并对比结果。

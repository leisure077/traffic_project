## 三、图2：24 小时出行/驻留折线

```python
dt = pd.to_datetime(label_df["time"], format="%Y%m%d%H%M%S")
tmp = pd.DataFrame({"hour": dt.dt.hour, "label": label_df["label"]}).dropna()
hours = list(range(24))
stay = tmp[tmp.label==0].groupby("hour").size().reindex(hours, fill_value=0)
travel = tmp[tmp.label==1].groupby("hour").size().reindex(hours, fill_value=0)
ax.plot(hours, stay, marker="o", color="#2ca02c", label="驻留点")
ax.plot(hours, travel, marker="s", color="#d62728", label="出行点")
ax.set_xticks(hours)
```

`reindex(range(24), fill_value=0)` 保证没有点的小时也显示为 0，曲线连续。

## 四、图3/4：目的、方式柱状（固定顺序，缺失补 0）

```python
PURPOSE_ORDER = ["居住","购物","旅游","其他"]
vc = df["final_purpose"].value_counts().reindex(PURPOSE_ORDER, fill_value=0)
```

**固定顺序 + reindex 补 0 很重要**：即使某类为 0（早期版本旅游恒为 0），图上仍保留该类别位置，不会让柱子错位。颜色与类别绑定：居住蓝、购物橙、旅游紫、其他灰。

方式顺序 `["地铁","公交","小汽车","其他"]`，颜色 地铁红/公交蓝/小汽车橙/其他灰，同样带"数量+百分比"标签。

真实：目的 居住234/购物165/旅游112/其他229；方式 小汽车37/其他29/公交28/地铁3。

## 五、图5：Top10 商圈 ×24 小时热力矩阵

```python
t = pd.to_datetime(heat_df["time"])
heat_df = heat_df.assign(hour=t.dt.hour).dropna(subset=["hour"])
pivot = heat_df.groupby(["biz_name","hour"])["count"].max().unstack(fill_value=0)
pivot = pivot.reindex(columns=range(24), fill_value=0)
top = pivot.max(axis=1).sort_values(ascending=False).head(10)

```

## 六、图6：Top5 用户 3D 时空轨迹

```python
ax = fig.add_subplot(111, projection="3d")
top_users = label_df["imsi"].value_counts().head(5).index
for i, u in enumerate(top_users):
    g = label_df[label_df.imsi == u].sort_values("_dt")
    z = g["_dt"].dt.hour + g["_dt"].dt.minute/60.0   # z轴=时间(小时)
    ax.plot(g["lon"], g["lat"], z, marker="o", markersize=3, label=f"用户{str(u)[-4:]}")
ax.set_xlabel("经度"); ax.set_ylabel("纬度"); ax.set_zlabel("时间(小时)")
ax.view_init(elev=25, azim=50)
```

x/y 是空间位置，z 是时间，于是"停留"表现为垂直上升的柱（位置不动、时间增加），"出行"表现为横向移动——一眼看懂时空轨迹，是项目最出彩的一张图。

# 课时 22：Pandas 时间处理（本项目重点中的重点）

## 一、两类时间输入

1. **13 位毫秒 UTC 时间戳**（原始数据首列）；
2. **`YYYYMMDDHHMMSS` 字符串**（清洗后、实时流首列）。

## 二、毫秒时间戳 → 北京时间（规则4，务必 +8）

```python
num = pd.to_numeric(df["time"], errors="coerce")
dt = pd.to_datetime(num.astype("int64"), unit="ms", utc=True) \
     + pd.Timedelta(hours=8)
df["time"] = dt.dt.tz_convert(None).dt.strftime("%Y%m%d%H%M%S")
```

逐行解释：

- `to_datetime(..., unit='ms')`：把毫秒整数当 UTC 时间解析；
- `+ pd.Timedelta(hours=8)`：加 8 小时转北京时间；
- `tz_convert(None)`：去掉时区标记，得到普通时间；
- `strftime("%Y%m%d%H%M%S")`：格式化成 `20181003004122`。

> 易错点：漏掉 +8 会让所有时间差 8 小时（首行 `1538498482636` 会变成 10 月 2 日 16:41，被目标日过滤掉一大半）。

兼容判断（代码里先检测是不是毫秒戳）：

```python
if num.notna().all() and (num.abs() >= 10**12).all():
    ...   # 毫秒分支
else:
    df["time"] = pd.to_datetime(df["time"], errors="coerce").dt.strftime("%Y%m%d%H%M%S")
```

## 三、字符串时间解析

## 五、时间差与速度

```python
sec = df.groupby("imsi")["time_dt"].diff().dt.total_seconds()
# 或
sec = np.diff(g["time_dt"].to_numpy()).astype("timedelta64[s]").astype(float)
```

注意长度对齐：`np.diff` 结果长度是 n-1，要和"相邻点距离（也是 n-1）"配对，否则会报形状不一致（这是 mode.py 修过的真实 bug）。

段时长：

```python
duration_h = (end_time - start_time).total_seconds() / 3600
```

## 六、floor：按分钟取整（热力图核心）

```python
stream["minute"] = stream["time_dt"].dt.floor("1min")
```

`12:30:45` 归到 `12:30:00`，从而按分钟聚合计数。

## 七、生成完整分钟序列（补齐缺失分钟）

```python

panel = panel.reindex(full, fill_value=0)
```

没有人流的分钟也要补 0，滑动窗口才连续。

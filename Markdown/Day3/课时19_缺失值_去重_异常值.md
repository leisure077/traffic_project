# 课时 19：缺失值、去重与异常值处理

## 一、缺失值 NaN / NaT

```python
df.isna()              # 每个格子是否缺失（布尔表）
df.isna().sum()        # 每列缺失数量
df.dropna(subset=["lon", "lat"])         # 关键字段缺失的行直接删
df["cluster"].fillna(-1)                 # 用-1填充
df["speed"].fillna(0)
```

项目中的三处典型处理：

1. 去空基站编号：`dropna(subset=["lac_id","cell_id"])`，并排除空字符串；
2. 基站关联失败的点没有 lon/lat：`dropna(subset=["lon","lat"])`；
3. 阶段3未参与聚类的点：cluster 用 `-1` 填充。

注意空字符串不是 NaN：

```python
df = df[(df["lac_id"].str.strip() != "") & (df["cell_id"].str.strip() != "")]
```

## 二、去重 drop_duplicates

```python
df.drop_duplicates()                         # 整行重复
df.drop_duplicates(subset=["imsi","time"])  # 指定键重复
df.drop_duplicates(subset=["laci"])          # 基站表每个基站只留一条
df.drop_duplicates(subset=["imsi","_minute"], keep="first")  # 分钟去重保留第一条
```

为什么要分钟去重：同一用户同一分钟可能有多条信令，若不去重，会被当成"停留了很多次"或产生 0 秒时间间隔、除零速度。实跑中分钟去重把 19983 行降到 17400 行（删 2583 行）。

## 三、异常值处理（速度最典型）

信令定位会"基站跳跃"，相邻两点可能算出几百 km/h 的假速度。处理：

```python
df.loc[(df["speed"] < 0) | (df["speed"] > 200), "speed"] = np.nan
```

把异常速度**置空而不是删除整行**，这样该点不参与速度判出行，但仍保留在数据里。

除零与负数：

```python
import numpy as np
with np.errstate(divide="ignore", invalid="ignore"):
    spd = dist_km * 3600.0 / secs
valid = (spd > 0) & (spd < 200)
avg = spd[valid].mean()
```

时间差为 0 会得到 inf，用布尔过滤即可。

## 四、replace / where / mask

```python
df["speed"] = df["speed"].where(df["speed"] <= 200)   # 不满足的变NaN
df["label"] = df["label"].replace({-1: 0})
```

## 五、脏字符串清洗

```python
df["imsi"].str.strip()
df[~df["imsi"].str.contains(r"[#* ^\s]", regex=True, na=False)]
```

实跑：532828 行里有 8 行脏 imsi、9 行空基站编号。

## 六、数据清洗的通用心法

1. **先看**：head / dtypes / isna().sum() / value_counts；
2. **定规则**：哪些直接删、哪些填充、哪些置空；
3. **留痕**：每步打印 before→after 行数；
4. **不误删**：能置空就不删整行（如异常速度），关键字段缺失才删行。

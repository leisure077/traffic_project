## 四、apply：逐元素/逐行自定义函数

```python
def is_night(h):
    return (0 <= h <= 6) or (20 <= h <= 23)

df["night"] = df["hour"].apply(is_night)        # 对一列逐值
df["purpose"] = df.apply(decide_purpose, axis=1)  # 对每一行，axis=1
```

`apply(..., axis=1)` 把整行作为一个 Series 传进函数，函数里用 `row["duration_hours"]` 等取字段。`purpose.py` 的综合判目的就是这么做的。

> 性能提示：能用整列向量化就别用 `apply`（apply 本质是循环）。本项目数据量小，apply 可读性好；Day8 会对比性能。

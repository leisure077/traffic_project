# 课时 17：行列选择与布尔过滤（清洗规则主力）

## 一、选列

```python
df["imsi"]               # 单列 Series
df[["imsi", "time"]]     # 多列 DataFrame
```

## 二、布尔过滤：选满足条件的行

```python
df[df["speed"] > 8]                       # 速度>8
df[(df["speed"] > 0) & (df["speed"] < 200)]   # 且，注意括号
df[(df["hour"] <= 6) | (df["hour"] >= 20)]    # 或
df[~df["imsi"].str.contains("#")]         # 取反 ~
```

> 多条件用 `& | ~`，**不要用** `and / or / not`；每个比较都要加括号。

## 三、字符串过滤（.str 访问器）

```python
df["time"].str.startswith("20181003")          # 是否以目标日开头
df["imsi"].str.contains(r"[#* ^\s]", regex=True, na=False)
df["mode_type"].str.contains("地铁", na=False)
```

`[#* ^\s]` 是正则字符集：匹配 `#`、`*`、空格或任意空白字符。`na=False` 表示空值按 False 处理。

## 四、isin：属于某个集合

```python
valid = counts[counts >= 20].index
df[df["imsi"].isin(valid)]      # 只保留点数>=20的用户
```

这是规则9"过滤稀疏用户"的关键。

## 六、"处理前→处理后"的调试习惯

每条过滤都记录删了多少行，方便核对：

```python
before = len(df)
df = df[df["time"].str.startswith("20181003")]
print(f"过滤目标日: {before} -> {len(df)}（删除 {before-len(df)} 行）")
```

真实运行时你会看到：跨天删除 14384 行、分钟去重删除 2583 行等具体数字。

## 七、loc：按条件改某些行的值（阶段3要用）


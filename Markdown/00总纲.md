# 交通时空大数据分析 · 8天60课时 教学总纲

> 面向只有 Python 基础的学生，8 天 60 课时，带你从零做出一个**能写进简历、能拿去面试**的真实大数据项目：
> 基于**手机信令数据**，分析一座城市里“人在什么时候停留、什么时候出行、出行去干什么、用什么交通方式、商圈什么时间最拥挤”，并生成 6 张可视化图表。
>
> 全部算法**手写实现**（K-Means 聚类、轮廓系数/邓恩指数选 K、Haversine 球面距离、滑动窗口），只用 `pandas + numpy + matplotlib` 三个库，不调用 sklearn、geopandas，便于你真正理解每一行代码。

---

## 一、课程目标（学完你能做到）

1. 说得清手机信令数据长什么样、能解决什么交通问题；
2. 独立完成“脏数据 → 干净数据 → 出行/驻留标签 → 目的/方式/热力 → 可视化”的完整链路；
3. 能手写 K-Means、Haversine、滑动窗口，而不是只会调库；
4. 掌握工程基本功：配置集中管理、函数封装、计时、日志、异常处理、一键运行；
5. 能基于真实跑出的数字做答辩、回答面试官追问。

## 二、最终项目成果

- 一套可运行项目代码 `traffic_project/`（11 个 Python 文件，`python main.py` 约 24 秒跑完全流程）；
- 7 个结果 CSV + 6 张 PNG 图表，输出在 `traffic_project/result/`。

## 三、数据与项目主线

```
原始手机信令(53万行, 无表头, 毫秒UTC时间戳)
   │  data_clean.py   9条清洗规则 + 按整用户抽样
   ▼
cleaned_data.csv（抽样后约 196 个用户、17362 个干净点）
   │  tr_stage1.py   删低频点 → 切段 → 相邻点速度 > 8km/h 粗筛
   ▼
stage1_travel_points.csv（806 个疑似出行点）
   │  tr_stage2.py   手写 K-Means，轮廓系数+邓恩指数自动选 K
   ▼
stage2_cluster.csv（275 个簇，其中单点簇 152 个）
   │  tr_stage3.py   三点距中心<1000m 且 首末跨度<2h → 驻留0，否则出行1
   ▼
stage3_label.csv（出行点 699 ≈ 4.0%，驻留点 16663 ≈ 96.0%）
   ├── purpose.py  驻留段 → 居住234 / 购物165 / 旅游112 / 其他229
   ├── mode.py     出行段 → 小汽车37 / 其他29 / 公交28 / 地铁3
   └── heatmap.py  25.6万实时流点 → 商圈10分钟人流（太原街峰值2570）
          └── visualize.py  一次生成 6 张图
```

> 上面的数字是**用真实数据、默认抽样（SAMPLE_ROWS=20000）真实跑出来的参考结果**，因抽样种子固定可复现；改 `config.py` 参数后数字会变，属正常。

## 六、环境与运行

```bash
# 1) 安装依赖（仅3个库）
python -m pip install -r traffic_project/requirements.txt
# 2) 一键运行
python traffic_project/main.py
# 3) 也可单步运行某个模块
python traffic_project/data_clean.py
```

- Python 3.9+；Windows 自带 SimHei 字体可显示中文图表。
- 数据路径由 `config.py` 自动定位“相关数据”文件夹；找不到时可把 6 个 CSV 放到 `traffic_project/data/`，或设置环境变量 `TRAFFIC_DATA_DIR`。
- 默认抽样 2 万行（`SAMPLE_ROWS=20000`），想跑全量改成 `0`。

## 七、给学生的学习建议

- **每节课先跑代码、再看讲解**：课时里的命令都能在 `traffic_project/` 目录直接运行。
- **改阈值做实验**：把 `config.py` 里的速度阈值、聚类阈值改一改，观察结果变化，这是面试时最好的谈资。
- **不怕报错**：Day8 专门讲怎么读报错、写测试、做性能优化，前期遇到错误是正常的。

# 课时 49：出行方式（中2）——地铁/公交站点空间匹配

## 一、为什么需要空间证据

地铁和小汽车都可能很快（平均速度 >20），光靠速度分不开。但：

- 地铁出行的轨迹点会靠近**地铁站**（进出站、沿线）；
- 公交出行会频繁靠近**公交站**；
- 小汽车通常不贴着地铁站走。

所以统计"一个出行段里有多少个点落在站点 500m 内"，作为判定证据。

## 二、统计靠近站点的点数（广播 Haversine）

```python
def count_near_points(point_lon, point_lat, st_lon, st_lat,
                      threshold=MODE_MATCH_THRESHOLD):   # 500m
    if len(st_lon) == 0 or len(point_lon) == 0:
        return 0
    d = haversine(point_lon[:, None], point_lat[:, None],
                  st_lon[None, :], st_lat[None, :], unit="m")   # (段内点数, 站点数)
    nearest = d.min(axis=1)        # 每个点到最近站点的距离
    return int((nearest < threshold).sum())
```

要点：

- 距离矩阵 `(p, s)`：段内每个点到每个站点；
- `min(axis=1)`：每个点到**最近**站点的距离；
- `<500` 后 `sum()`：有多少个点足够靠近站点。

### "同一多点只计一次"

我们数的是"有多少个点靠近站点"（对每个点的最近距离判一次），而不是"点×站点"的邻近对数。这样即使一个点旁边有 3 个公交站，也只给该点记 1，避免重复计数。

## 三、分别统计地铁、公交邻近点数

```python
sub_pts = count_near_points(lon, lat, sub_lon, sub_lat)   # 靠近地铁站的点数
bus_pts = count_near_points(lon, lat, bus_lon, bus_lat)   # 靠近公交站的点数
```

阈值常量：

- `MODE_MATCH_THRESHOLD = 500`（米）；
- `SUBWAY_MIN_POINTS = 2`（≥2 个点近地铁站才认地铁，避免偶发路过误判）；
- `BUS_MIN_POINTS = 3`（公交站密、线路多，要求更严格，≥3 个点）。

## 四、为什么地铁要求 2 点、公交要求 3 点

- 一个人可能恰好经过某个地铁站附近（路口、商场与站合建），单点证据太弱；
- 地铁一次出行通常进出站沿线会有多个点接近地铁站，要求 ≥2 能显著降低误判；
- 公交站更密集、几乎遍地都是，单点/双点靠近公交站非常普遍，所以门槛提高到 ≥3。

这是把"业务先验"编码成阈值的典型例子，面试时要能讲清为什么阈值不同。

## 五、距离阈值为什么是 500m

500m 是常用的公交/地铁"步行接驳距离"，且基站定位本身有误差，取太小匹配不到、取太大会把无关出行也算进来。可做 300/500/800m 的敏感性实验。

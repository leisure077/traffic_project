# 课时 11：广播机制（Broadcasting）——本项目最重要的 NumPy 技巧

## 一、什么是广播

形状不同的两个数组做运算时，NumPy 会**自动把小的数组"扩展"成相同形状**再逐元素运算，而不需要你写循环复制数据。这叫广播。

最简单的：

```python
import numpy as np
a = np.array([1, 2, 3])
print(a + 10)        # [11 12 13]，10被当成 [10 10 10]
```

数组之间：

```python
a = np.array([[1], [2], [3]])     # 形状 (3,1)
b = np.array([10, 20])            # 形状 (2,)
print(a + b)
# [[11 21]
#  [12 22]
#  [13 23]]   结果形状 (3,2)
```

## 二、广播的规则（记住"对齐维度，1 可拉伸"）

从最后一维往前比：

- 维度相等，或其中一个是 1，就兼容；
- 是 1 的那一维会被"复制拉伸"到另一维的长度；
- 缺的维度先补 1 再拉伸。

`(3,1)` 和 `(2,)`：把 `(2,)` 看成 `(1,2)`，再拉伸成 `(3,2)`。

## 三、本项目头号用法：一点（或一批点）对多个目标算距离

想算 **M 个段中心** 分别到 **P 个 POI** 的距离，结果是一个 `M×P` 矩阵。

把经度都摆好：

```python
center_lon = np.array([123.40, 123.41, 123.42])     # M=3，形状 (3,)
poi_lon    = np.array([123.40, 123.41, 123.42, 123.43])  # P=4，形状 (4,)

C = center_lon[:, None]      # 变成 (3,1) 列向量
P = poi_lon[None, :]         # 变成 (1,4) 行向量
print((C - P).shape)         # (3,4)：3个中心 × 4个POI 的全部配对
```

`[:, None]` 就是 `reshape(-1, 1)`：给数组加一个长度为 1 的轴。

在 `purpose.py` 中真正的写法：

```python
c_lon = agg["center_lon"].to_numpy()[:, None]   # (M,1)
c_lat = agg["center_lat"].to_numpy()[:, None]   # (M,1)
dist_m = haversine(c_lon, c_lat,
                   poi_lon[None, :], poi_lat[None, :], unit="m")  # (M,P)
nearest_idx = dist_m.argmin(axis=1)             # 每个中心最近的POI
```

`heatmap.py`、`mode.py` 也用完全相同的套路，只是换成"点 × 商圈""点 × 站点"。

## 四、K-Means 里的广播：一批点到所有簇中心的距离

`X` 形状 `(n,2)`，`centers` 形状 `(k,2)`，要算每个点到每个中心的距离，结果 `(n,k)`：

```python
# X[:, None, :] -> (n,1,2)
# centers[None, :, :] -> (1,k,2)
dist = np.sqrt(((X[:, None, :] - centers[None, :, :]) ** 2).sum(axis=2))
labels = dist.argmin(axis=1)     # (n,)，每个点最近的簇
```

这是手写 K-Means 的核心一行（课时 36 细讲）。

## 五、为什么要分批广播（控制内存）

`实时流`有 25.6 万个点、商圈 104 个，一次性算距离矩阵要 25.6万×104 ≈ 2668 万个数，虽然能算，但更大数据会爆内存。项目采用**分批**：

```python
BATCH = 10000
for s in range(0, n, BATCH):
    e = min(s + BATCH, n)
    d = haversine(p_lon[s:e, None], p_lat[s:e, None],
                  biz_lon[None, :], biz_lat[None, :], unit="m")  # (10000,104)
```

每批只算 1 万×104，内存可控。这是工程上处理大数组的常用手段。

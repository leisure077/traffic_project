# 课时 09：索引、切片与布尔筛选

## 一、普通索引回顾

```python
import numpy as np
a = np.array([10, 20, 30, 40, 50])
print(a[2])        # 30
print(a[1:4])      # [20 30 40]
print(a[::2])      # [10 30 50]，步长2
print(a[a > 25])   # 布尔索引：[30 40 50]
```

## 二、布尔索引：本项目最高频的操作

"只保留满足条件的行"在 NumPy 和 pandas 里都靠布尔数组：

```python
speed = np.array([3.0, 12.0, 30.0, 8.0, 9.0])
is_travel = speed > 8          # [False True True False True]
print(speed[is_travel])        # [12. 30. 9.]
```

多个条件用 `&`（且）、`|`（或），每个条件加括号：

```python
valid = (speed > 0) & (speed < 200)
night = (hour <= 6) | (hour >= 20)
```

## 三、二维数组的行列索引

```python
X = np.array([[123.40, 41.80],     # 点0
              [123.41, 41.81],     # 点1
              [123.42, 41.79]])    # 点2

print(X[0, 0])        # 123.4  第0行第0列
print(X[:, 0])        # 所有经度
print(X[0:2, :])      # 前两个点
```

用布尔数组筛"某些点"：

```python
mask = np.array([True, False, True])
print(X[mask])        # 第0、2两个点
```

## 四、花式索引（用整数数组取元素）

```python
idx = np.array([2, 0])
print(a[idx])         # [30 10]，按指定下标取
```

项目里用最近邻下标批量取结果：

```python
nearest_idx = dist.argmin(axis=1)          # 每行最小值列号
nearest_dist = dist[np.arange(len(dist)), nearest_idx]  # 每行最近距离
```

这里 `np.arange(n)` 提供行号 `[0,1,2,...]`，与 `nearest_idx` 配对，精准取出每行的最小值。

## 五、轴（axis）初识：按行还是按列

```python
M = np.array([[1, 2, 3],
              [4, 5, 6]])
print(M.sum(axis=0))   # [5 7 9]：沿行方向压，求每一列的和
print(M.sum(axis=1))   # [6 15]：沿列方向压，求每一行的和
```

记忆：**axis=0 跨行（结果按列），axis=1 跨列（结果按行）**。

```python
print(M.min(axis=1))   # 每行最小值 [1 4]
print(M.argmin(axis=1))# 每行最小值所在列 [0 0]
```

> 在"一批点 × 一批商圈"的距离矩阵里，`argmin(axis=1)` 就是"每个点最近的商圈列号"。

## 六、对应到项目代码

```python
d = haversine(p_lon[s:e, None], p_lat[s:e, None],
```

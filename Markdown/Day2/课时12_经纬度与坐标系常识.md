## 二、经度与纬度

地球用一个假想的经纬网定位：

- **纬度 lat**：相对赤道南北的角度，范围 `-90 ~ 90`，赤道 0，沈阳约 `41.8°`（北纬）；
- **经度 lon**：相对本初子午线东西的角度，范围 `-180 ~ 180`，沈阳约 `123.4°`（东经）。

本项目所有坐标大致在 `lon≈123.4、lat≈41.8`（沈阳城区）。

## 三、1 度经纬度大概多远

- 纬度方向：1° ≈ **111 km**（经线周长基本固定）；
- 经度方向：1° 的距离随纬度变化，约等于 `111 km × cos(纬度)`，在沈阳（41.8°）约 `111 × cos(41.8°) ≈ 83 km`。

所以同样差 0.01 度：

- 南北向 ≈ 1.11 km；
- 东西向（沈阳）≈ 0.83 km。

**经度和纬度的"单位长度"不一样，且地面是球面**——这就是不能直接 `√(Δlon²+Δlat²)` 当距离的原因。

## 四、常见的三种"错误/近似"距离

### 错误：直接把经纬度相减

```python
d = ((lon1 - lon2) ** 2 + (lat1 - lat2) ** 2) ** 0.5   # 得到的是“度”，不是米
```

单位是"度"，且经纬度尺度不同，无法直接对应真实米数。

### 近似 1：小范围平面近似（本项目聚类内部用）

在一个城市的几公里内，可以把经纬度先粗略换算成米，再用平面欧氏距离：

```python
x = (lon1 - lon2) * 111000 * np.cos(np.radians(41.8))   # 东西向米
y = (lat1 - lat2) * 111000                              # 南北向米
d = np.sqrt(x ** 2 + y ** 2)
```

误差在城市尺度很小。`tr_stage2.py` 在做 K-Means 时进一步简化，**直接在经纬度平面上用欧氏距离**（因为只是判断"哪些点更近、聚成几堆"，不需要真实米数；而涉及阈值判别的地方统一用 Haversine 米数）。

### 正规做法：Haversine 球面距离（下一课手写）

阈值判断（速度、1000m、500m）必须用真实米数/千米数，统一调 `utils.haversine`。

## 五、为什么项目里要"两套距离"

| 用途 | 用什么 | 原因 |
| --- | --- | --- |
| K-Means 聚类分堆、轮廓系数/邓恩指数 | 经纬度平面欧氏距离 | 只要相对远近，公式简单、算得快；城市小范围近似成立 |
| 速度 km/h、目的匹配 1000m、方式匹配 500m、商圈 1000m | Haversine 球面距离 | 要和真实阈值（米/千米）比较，必须准确 |

课堂上要能解释这个取舍——这是面试加分点。

## 六、角度与弧度

NumPy 的三角函数用**弧度**，而经纬度是角度，要先转换：

```python
import numpy as np
print(np.radians(180.0))     # 3.14159...
print(np.degrees(np.pi))     # 180.0
```

Haversine 公式第一步就是把所有经纬度 `np.radians`。

# 课时 08：数据类型与向量化运算

## 一、核心思想：向量化 = "整批一起算"

把 1 万个速度同时乘以 3600：

- Python 列表：写 for 循环，一个一个算，慢；
- NumPy 数组：直接 `arr * 3600`，底层用 C 一次算完，快几十上百倍。

```python
import numpy as np

speed_km_per_sec = np.array([0.002, 0.005, 0.01])
speed_kmh = speed_km_per_sec * 3600       # 整个数组一起乘
print(speed_kmh)                           # [ 7.2 18.  36. ]

a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
print(a + b)        # [11 22 33]  对应位置相加
print(a * 2)        # [2 4 6]
print(a ** 2)       # [1 4 9]
```

项目里速度计算就是向量化：

```python
# dist_km、time_diff 都是“整列数组”，无需循环
speed = dist_km * 3600.0 / time_diff_seconds
```

## 二、常用数学函数（对整个数组生效）

```python
x = np.array([0.0, 1.0, 2.0])
print(np.sin(x), np.cos(x), np.sqrt(x))
print(np.radians([180.0]))      # [3.14159]，角度->弧度，Haversine要用
print(np.sum(x), np.mean(x), np.max(x), np.min(x))
print(np.argmin([30, 5, 20]))   # 1：最小值所在下标（最近邻时用）
```

`argmin` 在项目里极其关键：**距离数组里最小值的下标，就是最近的那个商圈/POI 的编号**。

## 三、dtype：数组元素类型必须统一

```python
print(np.array([1, 2, 3]).dtype)          # int64
print(np.array([1.0, 2.0]).dtype)         # float64
print(np.array(["1", "2"]).dtype)         # <U1（字符串）
```

注意：

- 字符串数组不能直接做数学运算，要先 `astype(float)`；
- 读 CSV 时数字列若混入空格/空串可能变成 object，需要 `pd.to_numeric(..., errors='coerce')`。

```python
s = np.array(["123.4", "41.8"])
print(s.astype(float) * 2)
```

## 四、缺失值与异常值处理（向量化判断）

```python
spd = np.array([5.0, 250.0, -2.0, np.nan, 17.0])
valid = (spd > 0) & (spd < 200)        # 布尔数组
print(valid)                            # [ True False False False True]
print(spd[valid])                       # 只保留合理速度
print(np.mean(spd[valid]))
```

对应 `tr_stage1.py`：把 <0 或 >200km/h 的异常速度置为空。

## 五、性能对比：向量化为什么快

```python
import time
n = 1_000_000
lst = list(range(n))
arr = np.arange(n)

t = time.perf_counter()
s1 = [x * 2 for x in lst]
print("列表循环:", round(time.perf_counter() - t, 3), "秒")

t = time.perf_counter()
s2 = arr * 2
print("NumPy向量化:", round(time.perf_counter() - t), "秒")
```

数据量大时差距可达几十~上百倍。Day8 性能优化还会再讲。

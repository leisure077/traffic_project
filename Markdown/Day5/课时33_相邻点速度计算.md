# 课时 33：阶段1（中）——相邻点速度计算

## 一、速度 = 距离 / 时间

对同一用户、按时间排序的相邻两点：

- 距离：Haversine 球面距离（千米）；
- 时间：两条信令的时间差（秒），换算成小时。

```
speed(km/h) = 距离(km) × 3600 / 时间差(秒)
```

## 二、向量化实现（不写循环）

```python
df["time_diff"] = df.groupby("imsi")["time_dt"].diff().dt.total_seconds()
df["prev_lon"] = df.groupby("imsi")["lon"].shift(1)
df["prev_lat"] = df.groupby("imsi")["lat"].shift(1)

dist_km = haversine(df["prev_lon"], df["prev_lat"],
                    df["lon"], df["lat"], unit="km")
df["speed"] = dist_km * 3600.0 / df["time_diff"]
```

要点：

1. `groupby(imsi).diff()`：只在同一用户内部求时间差，每个用户第一条是 NaT；
2. `groupby(imsi).shift(1)`：取同一用户上一条坐标，防止串用户；
3. haversine 内部是 NumPy 运算，整列一次算完（17362→11184 行只要 0.02 秒）；
4. 每个用户第一行 prev 坐标为 NaN，距离/速度自然为 NaN，不会误判。

## 三、异常速度处理：基站跳跃

信令定位漂移会产生离谱速度（几百 km/h，远超高铁），时间戳异常还可能出现负值。处理：

```python
df.loc[(df["speed"] < 0) | (df["speed"] > ABNORMAL_SPEED), "speed"] = np.nan  # ABNORMAL_SPEED=200
```

为什么是**置空**而不是删行：这条点除了速度不可信，其位置和时间仍然有效（后面阶段3会用全量点），不应因一个特征异常就丢掉整条记录。

## 四、真实速度分布（806 个出行点）

```
count  806
mean   26.49 km/h
std    26.65
min     8.01
25%    11.86
50%    17.08
75%    29.03
max   197.17
```

中位数 17 km/h、大部分在 10~30 km/h，符合城市道路出行速度；上限 197 < 200，说明异常置空阈值合理。

## 五、为什么阈值取 8 km/h

```python
df["is_travel"] = df["speed"] > SPEED_THRESHOLD   # 8
```

- 步行约 4~6 km/h，骑行约 10~20 km/h；
- 取 8 km/h 能滤掉步行内的缓慢移动，把骑行以上的位移当作出行；
- "严格大于"且配合前面的低频点过滤，减少抖动误判。

阈值集中在 `config.SPEED_THRESHOLD`，改一个数字即可做敏感性实验。

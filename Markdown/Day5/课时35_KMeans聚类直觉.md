# 课时 35：无监督聚类与 K-Means 直觉

## 一、什么是无监督学习

- 有监督：数据带标准答案（如已知每张图是猫是狗），学一个预测器；
- **无监督**：数据没有标签，让算法自己发现结构。

**聚类（Clustering）**就是无监督的典型任务：把相似的点自动分成若干组（簇，cluster）。

我们的问题：某个用户的 806 个疑似出行点里（单看一个用户只有若干点），空间上其实分布在几个不同区域。把它们聚成 k 堆，才能进一步判断每堆代表"路过的一串点"还是"在一个区域活动的点"。

## 二、K-Means 的生活化比喻：分座位

想象教室来了一群人，要分成 k 个小组：

1. **选组长（初始化中心）**：先随便指定 k 个人当组长，站在 k 个位置；
2. **组员归位（分配）**：每个人走到离自己最近的组长那组；
3. **重选组长（更新中心）**：每组站到本组所有成员的"中心位置"（平均位置）当新组长；
4. **反复**：组员按新组长重新归位，组长再重新选……直到座位几乎不再变化。

对应到坐标点：

- 每个人 = 一个 (lon,lat) 点；
- 组长位置 = 簇中心（centroid）；
- 距离 = 平面欧氏距离；
- 迭代直到中心移动很小。

## 三、数学表达（很简单）

给定 k，目标是把 n 个点划成 k 个簇，使"各点到所属簇中心的距离平方和"尽量小：

```
目标：最小化  Σ 每个点到其簇中心的距离²
```

算法步骤：

```
1) 随机选 k 个点作为初始中心
repeat:
  2) 每个点分配给最近中心          （分配步）
  3) 每个簇用成员均值作为新中心     （更新步）
until 中心几乎不动或达到最大迭代次数
```

## 四、三个关键细节（面试常问）

1. **初始化敏感**：随机初始中心不同，结果可能不同。应对：固定随机种子可复现；真实工程常多次初始化取最优（如 sklearn 的 n_init，本项目固定种子保证课堂结果一致）。
2. **空簇**：某一轮可能没有点分到某个中心。应对：保留该中心不动，避免除零（本项目正是这么写的）。
3. **k 要预先指定**：聚成几堆？这是 K-Means 最大的问题——下一课用轮廓系数 + 邓恩指数自动选 k。

## 五、为什么城市小范围可用平面欧氏距离

K-Means 只需要比较"谁和谁更近"，不输出真实米数。在几公里城区内，直接用经纬度平面距离的相对远近关系几乎不变，所以：

- `tr_stage2.py` 聚类内部：用经纬度平面欧氏距离（简单快）；
- 涉及 1000m/500m/速度阈值：用 Haversine 真实距离（课时 12 的取舍）。

## 六、手动算一个极简例子（4 个点，k=2）

点：A(0,0)、B(1,0)、C(10,0)、D(11,0)，初始中心选 A、C。

- 分配：B 离 A 近→{A,B}；D 离 C 近→{C,D}；
- 更新：新中心 (0.5,0)、(10.5,0)；
- 再分配不变，收敛。得到两簇，完全符合直觉。

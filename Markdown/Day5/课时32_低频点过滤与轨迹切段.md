## 二、低频点过滤：去掉基站抖动/偶发路过点

思想：如果某个用户在某个坐标出现次数很少（<4 次），更可能是切换基站时的短暂路过或抖动信号，不代表稳定活动，先剔除。

```python
loc_cnt = df.groupby(["imsi","lon","lat"]).size().reset_index(name="cnt")
low_freq = loc_cnt[loc_cnt["cnt"] < LOW_FREQ_THRESHOLD][["imsi","lon","lat"]]  # <4

low_freq["_is_low"] = 1
df = df.merge(low_freq, on=["imsi","lon","lat"], how="left")
df = df[df["_is_low"].isna()].drop(columns="_is_low").reset_index(drop=True)
```

这是课时 21 讲的"反连接"：左连接一个低频标记表，没被标记（NaN）的才保留。

实跑：17362 → 11184（删 6178 行）。

> 注意：这里删的是"低频坐标点"，为后面算速度减少抖动干扰；阶段3做最终判定时会用清洗全量点（包括这些点，默认驻留0），保证标签覆盖全量。

## 三、轨迹切段：把连续相同位置编成段

为了描述轨迹，我们给"连续待在同一坐标"的点编同一段号，一旦换用户或位置变化就开新段。

```python
prev_imsi = df["imsi"].shift(1)
prev_lon  = df["lon"].shift(1)
prev_lat  = df["lat"].shift(1)

user_change = (df["imsi"] != prev_imsi)
loc_change  = (df["lon"] != prev_lon) | (df["lat"] != prev_lat)
seg_change  = (user_change | loc_change).astype("int64")

df["seg_id"] = seg_change.groupby(df["imsi"]).cumsum()
```

逐行理解：

1. `shift(1)` 取上一行；
2. 当前行与上一行"不同用户"或"位置变了"，seg_change=1；
3. 在**每个用户内部**对 0/1 标记 `cumsum()` 累加：每遇到一次变化，段号 +1；
4. `groupby(imsi)` 保证不同用户的段号互不干扰（不会把 A 用户尾和 B 用户头算成一段）。

实跑：切出 2558 个轨迹段。

## 四、为什么需要段号

- 段内点坐标相同：代表在该位置连续驻留的一串上报；
- 段与段之间发生位置变化：变化的那条边就是潜在"移动"；
- 后面 purpose / mode 还会用同样的"变化标记+cumsum"思路，分别对驻留点、出行点切段。这是本项目反复使用的**通用切段模式**。

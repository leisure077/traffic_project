# 课时 37：轮廓系数与邓恩指数——自动选最优 K

## 一、问题：K-Means 需要预先给 k，怎么定？

我们不知道一个用户的出行点到底聚成几堆。让 k 从 `K_MIN=2` 到 `K_MAX=10` 都试一遍，用一个"打分"衡量聚类好坏，选分数最高的 k。

好聚类的标准很直观：

- **簇内紧**：同一堆点彼此尽量近；
- **簇间分**：不同堆之间尽量远。

## 二、轮廓系数 Silhouette（综合簇内紧、簇间分）

对每个点 i：

- `a(i)`：点 i 到同簇其他点的平均距离（越小越紧）；
- `b(i)`：点 i 到"最近的另一个簇"所有点的平均距离（越大越分开）；
- 轮廓值：`s(i) = (b - a) / max(a, b)`，范围 -1~1，越接近 1 越好。

所有点取平均就是轮廓系数。

```python
def silhouette_score(D, labels):
    uniq = np.unique(labels)
    if len(uniq) <= 1:
        return 0.0
    n = len(labels)
    vals = np.zeros(n)
    for i in range(n):
        same = (labels == labels[i]); same[i] = False
        a = D[i, same].mean() if same.any() else 0.0
        b = np.inf
        for c in uniq:
            if c == labels[i]:
                continue
            other = (labels == c)
            if other.any():
                b = min(b, D[i, other].mean())
        denom = max(a, b)
        vals[i] = (b - a) / denom if denom > 0 else 0.0
    return float(vals.mean())
```

`D` 是点到点距离矩阵（下面用广播一次算好，避免重复）。

## 三、邓恩指数 Dunn Index

```
Dunn = 任意两个不同簇之间的最小距离 / 任意簇内部的最大直径
```

分子越大（簇间隔得开）、分母越小（簇内越紧），值越大越好。

```python
def dunn_index(D, labels):
    uniq = np.unique(labels)
    max_intra = 0.0
    for c in uniq:                       # 各簇最大直径
        idx = np.where(labels == c)[0]
        if len(idx) > 1:
            max_intra = max(max_intra, D[np.ix_(idx, idx)].max())
    min_inter = np.inf
    for i in range(len(uniq)):
        for j in range(i+1, len(uniq)):  # 簇间最小距离
            a = np.where(labels == uniq[i])[0]
            b = np.where(labels == uniq[j])[0]
            min_inter = min(min_inter, D[np.ix_(a, b)].min())
    if max_intra <= 0:
        return 0.0
    return float(min_inter / max_intra)
```

`np.ix_` 用于取"行集合×列集合"的子矩阵。

## 四、组合打分，遍历选 K

```python
def choose_best_k(X):
    n = len(X)
    if n < K_MIN:                       # 点太少，直接单簇
        return np.zeros(n, int), 1
    D = pairwise_euclidean(X)          # 距离矩阵只算一次，各K复用
    k_max = min(K_MAX, n)
    best_score, best_k, best_labels = -np.inf, 1, np.zeros(n, int)
    for k in range(K_MIN, k_max+1):
        labels, _ = kmeans(X, k)
        if len(np.unique(labels)) < 2:
            score = -np.inf             # 退化成单簇不给高分
        else:
            score = silhouette_score(D, labels) + 0.1 * dunn_index(D, labels)
        if score > best_score:
            best_score, best_k, best_labels = score, k, labels
    return best_labels, best_k
```

设计点：

- 距离矩阵 `D` 只算一次，遍历 k 时复用，省时间；
- **score = 轮廓系数 + 0.1 × 邓恩指数**：以轮廓系数为主、邓恩指数作为小权重的辅助修正（两者量级不同，用 0.1 平衡）；
- 只有 1 个点的用户直接单簇（n<K_MIN）。

## 五、真实运行的选 K 情况

806 个出行点分布在 126 个用户，逐人选 K：最优 K 最小 1、最大 10、平均 2.4，共 275 个簇。大多数用户出行点少，聚成 1~3 簇最合理，符合直觉。

## 六、这是很好的面试素材

面试官问"K-Means 的 k 怎么选"，你可以答：

1. 肘部法则（看误差随 k 下降的拐点）；
2. 轮廓系数（本项目手写实现）；
3. 邓恩指数；
4. 还可用 Gap statistic。并说明本项目用"轮廓系数+0.1邓恩指数"，在 K=2..10 里自动挑选。
